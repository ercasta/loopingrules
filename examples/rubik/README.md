# rubik

A Rubik's cube as triples. This is the base project of the Rubik example (design: [`doc/rubik.md`](../../doc/rubik.md)):

| File | What |
|---|---|
| `geometry.ttl` | **Knowledge**, generated by `gen_geometry.py`: the 54 facelet positions, the 20 edge and corner slots, the 6 quarter turns as 20 mappings each, and the 18 moves (`mv:U`, `mv:Ui` for U′, `mv:U2`). |
| `sheet.ttl` | **State**: a solved cube (one `rk:colour` per position), an empty plan, and a turn counter. Also generated. |
| `model.ttl` | **Shapes and operations**: `turn`, `scramble`, `reset`. |
| `method.ttl` | **Knowledge**, generated by `gen_method.py`: the beginner method's 7 stages and 72 cases. Stages 1–3 are searched for by the generator; stages 4–7 are textbook algorithms written by hand. |
| `solver.ttl` | **The solver**: 4 generic operations (start, plan a case, next stage, finish) and 2 controllers (case priority, stage end first). |
| `simulate.py` | Emulates the solver's rules in Python, to try a method on many scrambles in seconds. |
| `package.ttl` | The manifest. The project is in app mode: the cube only changes by turns. |

## Conventions
- **Faces:** white up, green front. The axes are x right, y up, z front.
- **Facelets** are numbered 1–9 in reading order, each face seen from outside:
  - U is seen with B at the top;
  - D is seen with F at the top;
  - F, R, B and L are seen with U at the top.
- **Clockwise** means clockwise as seen from outside the face.

## How a turn works
- **The plan** is an RDF list of moves: `rk:cube rk:plan ( mv:R mv:Ui … )`.
- **The `turn` operation:**
  - pops the head of the plan and increments `rk:turns`;
  - records `[] a rk:Executed ; rk:move mv:R ; rk:seq 17`;
  - moves 20 colours in one step. A step applies all its deletes and then all its inserts, so the colours move together.
- **Prime turns** use the same mappings in reverse.
- **Double turns** take a second step.

## Commands
Post these on `lr:in`, from the UI's I/O panel or `POST /api/in`:

```turtle
[] a rk:Scramble ; rk:moves ( mv:R mv:U2 mv:Fi ) .   # becomes the plan
[] a rk:Reset .                                      # back to solved
[] a rk:Solve .                                      # solve it, stage by stage
```

- **Commands wait while a plan runs.** They only match when the plan is empty.
- **Malformed scrambles are refused.** A scramble whose list holds something that isn't a move is refused by its shape.

## Run it
```bash
lr serve examples/rubik                 # tick listen, press Autopilot, post a scramble in the I/O panel
echo '[] a rk:Scramble ; rk:moves ( mv:R mv:U ) .' | lr run examples/rubik --listen
```

To regenerate the geometry: `python examples/rubik/gen_geometry.py`. To regenerate the method: `python examples/rubik/gen_method.py`, then check it with `python examples/rubik/simulate.py`.
