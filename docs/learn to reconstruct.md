I am thinking. To create a dataset for learning, would it be possible to start from a structured representation of something, perturb the structured representation by introducing a random change and automatically derive a tunable "restore" rule for that change, then put that rule, together with all the other rules, in a training process? In this way we could automatically create a dataset to tune the system. This seems like the CBOW - skip-gram training algorithm. One caveat; the rules should be initially withold, then the training process should attempt the repair with only the already known rules (because there might be more general rules, islands connected by bridges, that allow performing the "repair" without introducing more specific rules, favoring "acting from first principles")
